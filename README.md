# LUMI

### AI Study Intelligence Hub

> Un centro de comando inteligente para estudiantes, creado por **NubiWorks**.

LUMI nace para resolver un problema cotidiano del sector estudiantil: información, apuntes, tareas, fechas de entrega, sesiones de estudio y herramientas de IA repartidas entre demasiadas aplicaciones.

## Qué propone

LUMI reúne en una experiencia visual única:

- Dashboard académico y resumen del día.
- Planificador inteligente de tareas y entregas.
- Modo Focus para sesiones de estudio.
- Notas y tarjetas de conocimiento.
- Laboratorio de IA para estudiar, resumir, explicar y generar preguntas.
- Hub para conectar diferentes IAs y herramientas educativas mediante enlaces/proveedores configurables.
- Tema claro y oscuro persistente.
- Interfaz futurista con glassmorphism, hologramas y microanimaciones.
- Diseño responsive para computadora, tablet y celular.

## Ecosistema de IA

LUMI está pensado como un hub, no como una IA cerrada. Los proveedores pueden agregarse mediante configuraciones y enlaces externos. Las futuras integraciones con APIs deben utilizar variables de entorno y nunca exponer claves secretas en el frontend.

## Visión

Convertir a LUMI en una capa de organización académica que permita al estudiante elegir sus herramientas de IA sin quedar atado a un único proveedor.
